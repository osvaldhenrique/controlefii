# controlefii
Controle de Investimentos (Fundos Imobiliários)

Peguntas respondidas:
  Quanto investir por mês?
  Por quantos anos?
  Qual a taxa de rendimento mensal?
  Quanto de patrimônio vai acumular?
  Quanto vai receber de dividendos por mês?
  Qual a distribuição de carteira de acordo com meu perfil?

Como o VF e o PROCV entram nos cálculos:
  VF: entra para calcular as estimativas de patrimônio acumulado.
  PROCV: entra para calcular a distribuição da carteira, de acordo com o perfil.
